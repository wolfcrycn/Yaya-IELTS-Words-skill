# 每周训练轮换（听说读写）

`today` 会按星期几自动给出下面这套建议。它是**轮换**而不是每日四项全做——
每天 60–90 分钟的可执行量，比一份做不完的计划有用得多。

| 星期 | 主项 | 副项 |
|---|---|---|
| 周一 | 听力：剑桥 Section 1+2 精听，逐句听写 1 个 section（40min） | 阅读：True/False/Not Given 专项 1 篇（25min） |
| 周二 | 阅读：Passage 1 篇 + Matching Headings（25min） | 词汇：5 个新词造句（15min） |
| 周三 | 写作：Task 1 动态图 1 篇，限时 20min（30min） | 听力：Section 3 学术对话精听 + 跟读（20min） |
| 周四 | 口语：Part 2 话题卡 ×3，每题录音 2 分钟并回听（30min） | 词汇：口语高频搭配清单（15min） |
| 周五 | 写作：Task 2 大作文 1 篇，限时 40min，**必须批改**（50min） | 阅读：错题复盘，写出定位句（20min） |
| 周六 | 模考：完整一套听+读+写，严格计时（170min） | 口语：Part 1+3 模拟问答（20min） |
| 周日 | 复盘：只练强化池 + 顽固词（30min） | 看周报，定下周目标，重写跑题作文的提纲（25min） |

## 记录方式

```
ielts.py task --skill writing --name "Task2: 远程办公利弊" --minutes 50
```
`--skill` 取值：`listening` `reading` `writing` `speaking` `vocab` `mock` `review`

## 各单项最低有效剂量

- **听力**：精听 > 刷题。一个 section 听写三遍，胜过泛听两套题。
- **阅读**：先保正确率再保速度。定位句必须能写下来，写不出就是蒙的。
- **写作**：Task 2 每周至少 2 篇，且必须有人批改或用范文逐句对照。
  常见失分点是 TR（跑题/论证不充分）而不是词汇。
- **口语**：必须录音回听。 fluent 不等于高分，卡顿分布比卡顿次数更致命。

## 距考试 < 4 周的调整

1. 停发新词，全部时间给复习池 + 顽固词 + 真题词。
2. 写作每 3 天一篇完整限时，口语每 2 天一次录音。
3. 每周六固定模考，考后只做一件事：把所有错题分类（定位 / 同义替换 / 词汇 / 时间）。
